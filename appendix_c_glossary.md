# Appendix C — Glossary

> *"A shared vocabulary is the foundation of shared understanding."*

## Notation Reference

> **Planned content:** Tensor dimension notation used throughout the guide. Convention: `[B, C, H, W]` for image batches (B=batch, C=channels, H=height, W=width). `[B, T, D]` for sequences (T=time/length, D=dimension). `[N, 4]` for bounding boxes (N=number of boxes, 4=coordinates). Superscripts for layer index. Subscripts for channel/class index.
